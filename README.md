Лабораторная работа — вариант 8

Тема

Создание консольной программы на C# с использованием класса "Student".

Цель работы

Научиться создавать класс, хранить данные о студенте, выводить их на экран и рассчитывать среднюю оценку.

Что было сделано

- Создан класс "Student".
- Добавлены поля для ФИО и двух оценок.
- Реализован метод "Show()" для вывода данных студента.
- Реализован метод "SredOcenka()" для расчёта средней оценки.
- Создан объект класса и заданы исходные значения.

Результат

ФИО: Иванов
Оценка 1: 3
Оценка 2: 5
Средняя оценка: 4

Вывод

В ходе лабораторной работы изучено создание классов и объектов в C#, вывод данных и вычисление среднего значения.
